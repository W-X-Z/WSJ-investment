# ADR-0023: 제품 형태 — 기업 리서치 리포트 피드와 이슈 피드, 나머지는 수납

상태: accepted (2026-10-29). 사용자가 원하는 워크플로우와 화면을 그대로 적는다.

## 사용자가 원하는 것
워크플로우
1. 최신 이슈·데이터 수집.
2. 온톨로지 기반 가설 생성:
   - A. 주요 이슈·데이터가 업계에 어떤 영향을 줄지 — **이슈당 경로 최대 3개**.
   - B. 그 가설을 고려해 **텐배거 후보 기업의 간이 리서치 리포트**: 목표주가, 추론 요약, 데이터 근거.
   - 추가 리서치가 필요하면 중간중간 실행.

화면
- **리서치 피드**: 종목 리서치 리포트 요약 — 이 기업의 투자 아이디어, 목표주가, 근거를 간단히. 클릭하면 상세.
- **이슈 피드**(다른 탭): 최근 이슈와 그 이슈가 공급망에 어떤 의미를 갖는지.
- 나머지 화면은 수납.

## 결정
1. **용어**: 아이디어 = 기업 리서치 리포트. 가치평가의 확률가중 기대 주가(12개월) = **목표주가**, 약세·기본·강세 내재 주가가 범위. verdict = 추론 요약.
   모형 산출이지 권유가 아니라는 문구는 유지한다 (ADR-0019 의 '목표가 금지'는 표현 규칙이었고, 사용자가 명시적으로 목표주가를 원하므로 바꾼다).
2. **2A 는 1단계 가설의 형식**이다 (ADR-0022 보완): 이슈마다 영향 경로 ≤3, 기업이 없는 경로도 받는다. 이슈별 경로는 `ideas.issue_hypotheses` 에 저장(0026)하고
   이슈 탭이 보여 준다. 기업이 붙은 경로만 리포트 후보(2B)가 된다.
3. **2B 는 2단계 아이디어 + 가치평가**다 (ADR-0019·0020·0022). 추가 리서치 = 조사 계획대로 원문 확인 → 기업 소식·관측치 저장 → 2차 입력.
4. **화면**: 홈 = 리서치 피드(리포트 요약 카드: 기업·목표주가·투자 아이디어·근거·예측 상태), `/issues` = 이슈 피드(이슈 · 공급망에서의 의미 · 영향 경로 · 연결된 리포트).
   사이드바는 두 탭만 1차 메뉴로, 나머지(병목 보드·시스템 점검·지표·그래프·발굴·해자·이전 피드·데이터 아카이브)는 '더 보기'로 수납.

## 개정 2 (2026-10-29): 메인 문턱 · 기업 위키 · 가중치 그래프 · 목표주가 의무
사용자 피드백: "근거가 약하면 메인에 올리면 안 된다 (기댓값이 아주 크면 몰라도)", "이슈 상세에서 리포트와 관련 기업을 나눠라 — 기업 위키를 따로",
"한쪽 윤곽선 색 띠는 쓰지 마라", "그래프는 중요한 흐름만 — 가중치", "목표주가가 빠진 실행은 네가 고쳐라".
1. **메인 문턱** (`onFeed`): ★2 이상이거나, 오늘 종가로 다시 계산한 여력이 **+30% 이상**(반올림 기준)인 리포트만 홈에 둔다. 나머지는 `/ideas` 의 '검토 중'. 홈 밑에 '검토 중인 가설 N' 링크 하나.
2. **낡은 목표주가**: 리포트를 고쳐 쓴 시각(updated_at)보다 앞선 산출은 그 리포트의 값이 아니다 → 카드·문턱에서는 '없음'으로 치고 '재산출 대기 · 이전 값'만 작게.
3. **목표주가 의무** (엔진): 가격·주식수가 있는 new·update·weaken 행에 valuation 이 없으면 `valuation missing` 으로 **exit 2** (세션 모드; `--allow-missing-valuations` 로만 우회).
   한 번도 평가되지 않은 keep 도 같은 규칙. 실행 끝에 `select count(*) from ideas.valuations where as_of = current_date` 로 확인하고 보고에 적는다 (daily-ideas §4·§5·§6-1).
4. **기업 위키** `/companies/[slug]`: 공급망 위치(공급·개발 / 푸는 병목 / 동종 / 고객) · 시세·재무 · 이 기업에 닿는 변화(impact-index) · 리포트 · 관련 리포트 · 소식 · 이슈.
   이슈 상세는 머리 → 영향 경로(그래프) → **리포트**(이 이슈를 근거로 쓴 것) → **관련 기업**(수집기가 읽은 기업 + 경로 끝 기업, 위키로)으로 나눈다.
5. **가중치 그래프**: 이웃 전부가 아니라 **가중치 상위 K(8) 경로**만. 가중치 = impact-index 경로 신뢰도(간선 근거 등급의 곱) + 범위 안 0.08 + 리포트 있음 0.15; 1단계 가설 경로는 점수/12 로 위에 얹는다.
   열은 종류가 아니라 **단계**(변화 → 1차 → 2차 …)라 기업→공급사 고리도 왼쪽에서 오른쪽으로 읽힌다. 굵기 = 신뢰도, 색 = 가설 경로, 점선 = 그래프에 없는 추론 고리, 뺀 경로 수를 적는다.
   신뢰도는 '근거가 단단한가'이지 '영향이 큰가'가 아니다 — 크기는 가설 경로의 effect_pct(0026) 가 말한다.
6. **스타일**: 카드·상세의 한쪽 색 띠 제거, 추세 태그(가설 약화 등) 카드에서 제거, 생태계는 글자로만.
