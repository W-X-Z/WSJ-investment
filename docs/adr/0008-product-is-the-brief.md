# ADR-0008: 제품은 "텐배거 후보 브리프" — 백테스트·모의투자 제외, 섹터 확장

- 상태: accepted
- 날짜: 2026-10-26
- 대체: [ADR-0007](0007-alpha-hypothesis-and-validation-order.md) 의 "검증 순서(백테스트 → 에이전트)" 와 "두 개의 북" 조항. 0007 의 알파 가설·청산 원칙은 유지.

## 맥락

사용자 정의 (2026-10-26): *"필요한 건 투자 아이디어·리스크·하드데이터를 잘 정리해서 텐배거 후보 종목을 알려주는 서비스. 100% 투자는 없다. LLM 의 생산성과 시스템으로 승률을 최대한 높일 뿐. 중요한 건 더 다양한 원천의 데이터·정보를 잘 연결하고 해석해서 기회를 발굴하는 시스템."*

따라서:
- 20년 백테스트는 퀀트의 도구다. 환경이 다르고, 우리는 통계적 알파를 증명하려는 게 아니다. 유료 가격 데이터도 쓰지 않는다.
- 모의투자 연동은 불필요. 매매는 사용자가 직접.
- 검증은 **포워드 채점**으로 대체: 브리프마다 날짜 박힌 예측을 남기고 분기마다 맞았는지 채점한다.

## 결정

1. **산출물 = 브리프.** 종목 하나에 대해 (왜 지금) + (하드데이터·원문 링크) + (투자 아이디어) + (리스크) + (반증 조건) + (점수). `ideas.briefs` 에 저장, 조회 화면에서 본다.
2. **부서 역할 조정.** Data Desk(수집·연결) → Analyst(해석·아이디어) → Risk(리스크 작성, 거부권 아님) → 사용자. `orders`/`fills`/`decisions` 스키마는 보류 (삭제하지 않음).
3. **연결 레이어가 먼저.** raw 를 종목 단위로 잇는 `core.signals` / `core.candidates` 를 LLM 없이 규칙으로 만든다. 후보 = 서로 독립적인 두 계열 이상의 신호가 90일 안에 겹친 종목. LLM 은 후보에만 쓴다.
4. **비용 모델.** 엔티티 매칭·신호 생성은 LLM 을 쓰지 않으므로 유니버스 크기와 무관하게 거의 무료. LLM 비용은 **후보 수**에 비례한다 (브리프 1건 ≈ 10-K 사업 섹션 + 8-K + 신호 ≈ 50~100k 입력 토큰). 주 20건이면 월 수십 달러 수준. 따라서 비용 때문에 도메인을 좁힐 필요는 없고, **관심 섹터로 좁히는 건 집중의 문제**다.
5. **섹터 확장.** 사용자 관심(에너지·AI·반도체)을 유니버스에 추가한다. 데이터 두께는 바이오·정부조달보다 얇지만 SEC(Form 4·8-K·10-K)·FINRA·USAspending(에너지·방산)·EIA/NRC(에너지) 는 그대로 적용된다. 버킷은 설정으로 켜고 끈다 ([ADR-0004](0004-initial-universe.md) 의 SIC 집합 확장).
