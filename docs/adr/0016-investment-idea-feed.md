# ADR-0016: AI 투자 아이디어 피드 — 데이터는 AI 의 재료, 사람은 아이디어와 근거만 본다

- 상태: accepted
- 날짜: 2026-10-27
- 관련: [ADR-0015](0015-data-architecture.md) (개정 1 로 단순화), [ADR-0014](0014-supply-chain-issue-feed.md) (이슈·지표), [ADR-0013](0013-discovery-and-moat-cards.md) (해자 카드)

## 1. 맥락 (사용자, 2026-10-27)

> 내가 이 데이터들을 엄청 유의 깊게 보지는 않을 거야. 결국은 AI 가 투자 아이디어를 논리적으로 도출하기 위해 사용하는 용도에 가깝다. 피드로 투자 아이디어와 그 근거를 보여주는 게 제일 중요해. 직관적인 투자 아이디어.

그래프(852 노드)·이슈·지표·공시는 사람이 탐색하는 화면이 아니라 **AI 의 추론 재료**다. 사람이 보는 1차 산출물은 **투자 아이디어 피드**다.

## 2. 결정

### 2-1. 아이디어 = 결론 + 근거 사슬
- **제목:** 투자자가 바로 이해하는 한 문장 + 기업명. 예) "AI 기판이 모자랄수록 기판 소재 독점 기업이 먼저 웃는다 — 미쓰이금속"
- **thesis:** 두 문장 — 무엇이 바뀌었나 / 왜 이 기업인가.
- **★1~3:**
  - ★3 = 최근 사실이 병목·전환을 직접 확인 + 공급이 소수에 집중 + 기업 노출이 공식 근거.
  - ★2 = 셋 중 둘.
  - ★1 = 하나 또는 추론 의존.
- **유형:** 병목 수혜 / 기술 전환 / 실적·가격 확인 / 리스크.
- **근거 사슬 3~5 단계:** "변화 → 병목·전환 → 공급 구조 → 기업". 각 단계는 출처 링크(근거 등급 포함)로 뒷받침되고, 첫 단계는 반드시 최근 신호다. 기술 추론만으로 이어진 단계는 "(추론)"으로 표시한다.
- **리스크(반대 근거)·다음 확인 신호(watch)·관련 기업(역할·한 줄 이유).**
- 주가·목표가·매수/매도 권유·시점 예측은 쓰지 않는다.

### 2-2. 엔진 (`wsj.ecosystems.ideas`, 매일 이슈 수집 직후 — `issues.yml`)
1. **신호:** 최근 21일 이슈(★2 이상)와 눈에 띄는 지표(대만 월매출 YoY ≥40% 또는 ≤−20%, 미국 PPI |YoY| ≥10%). 이슈 문장과 출처 제목을 지금 그래프 어휘로 다시 태깅한다 — 그래프가 커지면 예전 이슈도 새 노드에 닿는다.
2. **후보 사슬 (결정적):** 신호 노드에서 `impact.influence_paths` 로 기업까지의 경로를 구한다.
   - 점수 = Σ(신호 ★ 가중 × 노드 특이도 1/√도달기업수 × 경로 신뢰도) × 규모 가중(초소형 1.6 … 초대형 0.3, 비상장 제외) × 공급 집중(공급사 1곳 1.5 … 7곳+ 0.8).
   - 같은 부품의 공급사는 3곳까지만 넣고, 생태계별로 최소 몫을 둔다.
   - 각 후보에 동종 공급사와 기술 전환 관계(대체·개발·IP, 성숙도)를 붙인다.
3. **근거 목록:** 신호 출처는 S…, 그래프 관계 출처는 G… 로 id 를 매긴다. LLM 은 이 id 만 인용할 수 있다 (URL 을 지어낼 수 없다).
4. **LLM (기본 Sonnet, 1회 ≈ $0.2):** 기존 활성 아이디어를 함께 받아 new / update / weaken / keep / close 를 정한다. 같은 논리는 같은 key 로 갱신된다.
5. **검증:** 다음 경우는 버린다.
   - 없는 근거 id 나 없는 기업
   - 근거 있는 단계가 2개 미만인 사슬
   - 최근 신호 근거가 없는 새 아이디어

   종료(close) 행은 상태·사유만 바꾼다.
6. **저장:** `ideas.investment_ideas`. 내용이 바뀌면 트리거가 이전 행을 `ideas.idea_revisions` 에 남기고 revision 을 올린다. 21일 갱신이 없으면 `stale`.

### 2-3. 화면
- **홈 = 아이디어 피드.**
  - 카드: ★ · 유형 · 제목 · thesis · 기업 칩(티커·규모, 소형주 ★) · 근거 수 · 갱신 시점 · 새로/강화/약화 배지.
  - 아이디어 상세: 결론 → 논리 단계(단계마다 출처 링크) → 리스크 → 지켜볼 것 → 관련 기업(캔버스로 이동).
- **근거 데이터 메뉴:** 이슈 피드, 가격·실적 지표, 산업망 캔버스, 공급사 발굴, 해자 카드. 사람이 굳이 보지 않아도 되지만 확인하고 싶을 때 찾아가는 곳이다.
- 마이그레이션 적용 전에는 홈이 리포에 묶인 시드(`apps/web/src/data/ideas-seed.json`, 세션에서 같은 엔진·검증으로 만든 8건)를 보여 준다.

## 3. 결과와 비용
- 매일 Sonnet 1회 추가 (입력 ≈ 4만 토큰). 품질이 부족하면 `ideas_model=opus` 로 수동 실행.
- 아이디어의 정확도는 그래프 품질에 묶인다 → 그래프 확장·검증이 곧 아이디어 품질 개선이다. 추론(technical_inference) 관계만으로 이어진 아이디어는 ★1 에 머문다.
- 채점(아이디어가 맞았나)은 다음 단계 — watch 신호가 실제로 나왔는지 다음 실행이 판정해 강화/약화로 남긴다.

## 개정 1 (2026-10-27) — 최신 근거 우선, 기업별 최신 소식 파이프라인
**문제.** 아이디어의 근거 사슬이 최근 이슈(S) 한두 개에 오래된 그래프 관계 출처(G, 2023~2025년 자료·날짜 없는 제품 페이지)를 이어 붙여, 읽는 사람에게 "과거 자료로 만든 아이디어"로 보였다. 이슈 피드는 산업 단위 기사 위주라 기업 자신의 최근 공시·실적·수주가 신호로 들어오지 않았고, 대만 월매출·PPI 같은 월간 지표는 한 달 늦다.

**결정.**
1. **기업별 최신 소식 (`wsj.ecosystems.company_feed`).** 그래프의 상장 기업 339곳에 대해 매 실행 최근 14일을 모은다. 모두 무료 공개 출처다.
   - 미국: SEC EDGAR submissions (8-K item 을 한국어로, 계약·실적 공시는 EX-99 보도자료 헤드라인)
   - 대만: TWSE·TPEx 일일 중대공시, 그리고 지표 모듈 밖 그래프 기업의 월매출 중 눈에 띄는 달 (YoY ≥ +30% 또는 ≤ −20%, MoM ±25%)
   - 일본: TDnet 적시공시 목록 / 중국: 巨潮资讯(cninfo) 공시 / 한국: DART OpenAPI (`DART_API_KEY` 가 있을 때)
   - Google News 기업명 검색 (+ `research/ecosystems/native_names.json` 의 현지어 이름으로 한·일·중 현지 기사). 소형·중형은 매번, 대형·초대형은 기존 아이디어 기업일 때만. 제목에 기업명이 없거나 시세 기사(주가 등락·목표가)면 버린다.
   - 행정·절차 공시(주총·자사주·이사회 결의·정관 등)는 버리고 수주·계약·실적·업적 수정·증설은 중요도를 올린다.
2. **누적 (`ideas.company_events`, 마이그레이션 0019).** 대만 중대공시 API 는 당일분만 주므로 실행마다 쌓아야 2주 창을 볼 수 있다. 엔진은 "지금 수집 + DB 에 쌓인 14일"을 합쳐 쓴다. 0019 적용 전에는 저장 없이 이번 수집분만 쓴다.
3. **엔진.** 기업 소식은 기업 단위 신호(E…)가 된다 — 사건성(★2+)이 있거나, 노드를 태깅하거나(한·중·일 용어 포함), 기존 아이디어 기업일 때만. 모든 신호 가중에 반감기 7일의 최근성 계수를 곱한다. 기업 소식이 태깅한 노드로는 약하게(0.35) 퍼진다 — 소식의 주어는 그 기업이다.
4. **프롬프트·검증.** 첫 단계는 최근 사실(날짜 포함)이어야 하고, G 근거는 구조 설명에만 쓴다. 14일 안의 S 근거가 없는 새 아이디어와 갱신(update)은 버린다. `last_signal_at` 은 인용한 S 근거 중 가장 최근 날짜. `stale` 은 갱신 시각이 아니라 이 날짜가 21일을 넘었는지로 본다.
5. **화면.** 카드에 "최신 근거 N일 전", 근거 링크에 날짜(최근 14일이면 초록), 그래프 근거는 "배경" 표시. 같은 ★ 안에서는 근거가 새로운 아이디어가 위로. 상세 화면에 "관련 기업 최근 소식"(공시·월매출·뉴스, 30일).
6. **실행 주기.** 하루 두 번 — 06:47 KST(미국 장 마감 뒤), 18:47 KST(아시아 장 마감·공시 뒤). 한 번에 ≈ $0.4.

**남은 것.** 주가·거래량 이상 신호(야후 차트가 컨테이너에서 429 — Actions 러너에서 재확인), 유럽 상장사 공시, 실적 발표 일정 캘린더.
