# ADR-0031: 온톨로지 v0.5 — 신호를 놓는 지도로 (시간 축 · 층별 식별자 · 규칙과 결정 주체 · 숫자 노출도 · 후보 노드)

상태: proposed (2026-11-02). 사용자 승인 뒤 accepted. ADR-0012(닫힌 어휘 v0.3)·v0.4 를 잇는다. 구현은 백로그 G-1~G-8.

## 맥락 (2026-11-02 측정)
- 온톨로지는 에이전트가 조사·분석을 더 효율적·정확하게 하는 도구여야 한다 (사용자). 지금은 수집 범위를 정하는 데(그래프 상장사 이름 검색) 가장 많이 쓰여 닫힌 고리를 만든다.
- 뼈대(수요 동인 → 세대·표준 → 요구 → 병목 → 기술·공정·부품·소재·장비 → 제품 → 기업)와 근거 등급·검증기는 쓸 만하다. 노드 913 · 관계 1,720.
- 비어 있는 곳: 공급 관계 666개 중 노출도(매출 비중) 3개(0.5%), 자리 1개, 납품 관계 15개. 날짜가 없다(성숙 단계는 78개 노드에 현재 값 하나). 별칭은 대부분 영어 일반 용어이고 표준 번호·특허 분류·HS 코드가 없다 — 단서의 기술 노드 연결률 12%. 규칙·결정 주체가 없다(ride-through 분석의 핵심이던 '누가 결정하고 언제부터 강제되나'를 못 담는다). 사전 밖 용어가 들어올 자리가 없다(10건).
- 칸이 있어도 누가 무엇으로 채우는지 정하지 않으면 비어 있다 (노출도가 그 예).

## 결정
| 더하는 것 | 모양 | 누가·무엇으로 채우나 |
|---|---|---|
| 시간 축 | 노드·관계에 `first_seen`(우리가 처음 본 날), `first_evidence`(근거상 처음 나온 날). 성숙 단계는 `maturity_history: [{stage, date, evidence}]` 로 쌓는다 | 수집 코드(처음 본 날), 해석·검토(근거 날짜·단계 전환) |
| 층별 식별자 | 노드 `codes: {cpc, jesd, oif_ia, ieee, rule, hs, part}` 와 한·중·일 별칭(`node_aliases.json` 확장) | 원본 수집기를 붙일 때 정리, 주간 개선이 보강, 사전 밖 용어 통로 |
| 규칙·결정 주체 | 노드 종류 `rule`(NOGRR282, NERC 표준, PJM 매뉴얼, 수출통제 조항)·`authority`(계통 운영자, 규제기관, 표준기구, 하이퍼스케일러). 관계 `mandates`(rule → requirement, `effective_date`), `issued_by`(rule → authority) | 규제·계통 페이지 변화 감지 결과를 해석이 확인 |
| 숫자 노출도와 양 | `offered_by` 에 `exposure_pct`·`exposure_year`·`exposure_source` (범주 `exposure` 는 남긴다). `requires` 에 선택 칸 `content_usd_per_system`·`lead_time_weeks` | 10-K·20-F 주요 고객·제품 비중, 대만 월매출, cninfo IR 기록 — 해석·검토가 조사하며 제안으로 남긴다 |
| 후보 노드 | 노드 `status: candidate|active`. 후보는 근거 1개로 들어오고, 두 층 이상에서 보이거나 매출 근거가 붙으면 active | 수집 코드(사전 밖 용어·그래프 밖 상장사), 검토자(승격) |

- 원본은 Git(`seed_graph.json` + 패치 + CI 검증)에 그대로 둔다. Supabase 에는 병합될 때마다 조회본을 만들고(G-2), 조회 함수(G-3)와 제안 테이블(G-4)로 모든 예약 작업이 쓴다.
- 품질 규칙은 유지한다: 납품 관계는 공식 근거 이상, 한 출처당 관계 최대 12개. 노출도 숫자는 원문 숫자가 있을 때만. 근거가 12개월 넘으면 재확인 대상.
- 하지 않는 것: 범용 온톨로지 표준(OWL·RDF)으로 옮기기. 그래프가 작아 JSON + 검증기 + DB 조회본이면 충분하다.

## 결과
- 기존 데이터는 빈 칸으로 옮기고(`migrate_v05`), 검증기는 새 칸을 선택 칸으로 받는다 — 지금 그래프를 깨지 않는다.
- 확장은 신호가 온 곳부터 깊게: 원본 신호가 놓인 노드의 2~3단계 아래(공급사·소재·장비)를 근거와 함께 채운다. 전수 채우기는 비용을 먼저 알린다(G-8).
- 주간 점검(채점 아님): 노출도 채움률, 단서의 기술 노드 연결률, 후보 수·승격 수, 오래된 근거 비율.
