# ADR-0027: 매일 테제 사슬 — 큰 테제를 작은 테제로 쪼개고, 소형주까지 매일 발굴한다

상태: accepted (2026-10-30). ADR-0024 의 paths 작업을 discover 로 바꾸고, ADR-0025·0026 의 주간 thesis 작업(토 09:17 — 등록되지 않았다)을 매일 사슬에 접어 넣는다.
관련: ADR-0020(가설 우선) · 0021(미국·한국) · 0022(검증 루프) · 0023(목표주가) · 0026(새로움 우선).

## 맥락
1. **두 갈래가 따로 돌았다.** 매일 사슬(수집 → 경로 → 조사 → 리포트 → 검증)은 뉴스 이슈에서 출발하고, 테제(구조 가설)는 토요일 작업 하나가 따로 맡았다. 매일 사슬이 테제에 주는 것은 경로에 붙는 `thesis` 태그(+ 근거)뿐이었는데,
   평가(2026-10-30)에서 '+' 근거는 가치가 낮았다 — 뉴스는 가격을 뒤따르고, 태그는 이미 움직인 체제(regime)에 몰렸다. 가치가 있었던 것은 **반박**이었다 (10/30 조사가 MACOM CW 레이저 양산 2027 말 이후·Coherent InP 외판 없음을 원문으로 확인해 내 메모를 뒤집었다).
2. **테제가 너무 크다.** 활성 테제 9개의 primary 는 거의 대형주다(SK하이닉스·삼성전자·Micron·Broadcom·효성중공업). 큰 테제는 맞아도 대형주가 먼저 반영하고(메모리 재현: 2025-10 → 2026-06 에 이미 7배), 판정까지 1~2년이 걸린다.
   사용자(10/30): "지금 테제들이 너무 큰 단위로 나오는데, 사실 작은 규모에서도 투자 기회가 많을 것 같아." 재현에서도 놓친 것은 하류의 작은 고리였다(삼성전기 FC-BGA +1,015%).
3. **우주가 대형주 쪽이다.** 그래프 기업 403개 중 미국·한국 소형·초소형은 46개(한국 15)뿐이다. 예약작업은 파이프라인 코드를 바꾸지 않으므로 새 소형 공급사를 넣을 길이 주간 개선 작업 하나였다.

## 결정
### 1. 사슬 하나, 작업 다섯 (시각은 그대로)
| 작업 | 시각 | 하는 일 |
|---|---|---|
| collect | 05:23 | 그대로 |
| **discover** (← paths) | 06:17 | ① 이슈 경로(그대로) ② 오늘의 약한 신호 스캔(요일별 출처) ③ **작은 테제 최대 3개** ④ 새 소형 공급사를 JSON 그래프 패치로 |
| research | 06:49 | **작은 테제의 가장 약한 고리를 반박 우선으로** 먼저 → 남은 칸에 선택 경로 (합쳐 최대 8) |
| report | 07:37 | 선택 경로 + **조사에서 살아남은 작은 테제의 primary** 로 리포트·목표주가 |
| verify | 08:11 | 예측 채점 + **테제 감시(반증 기한·첫 신호)** + 단계 판정 · 토요일은 큰 테제 점검(드라이버·단계·조용함) |
앞 작업이 아직 running 이면 다음 작업은 최대 30분 기다린다 (공통 §0).

### 2. 두 크기 — macro 와 micro
- **macro** (지금까지의 테제): 사용 방식의 변화 → 자원 요구 → 병목 → 리레이팅. 여러 해, 대형주 허용. 새 macro 는 토요일에만, 주 1개까지 (ADR-0026 절차 그대로).
- **micro** (새로): **한 기업의 한 제품·한 고객·한 계약에서 생기는 변화** 가 6개월 안에 숫자로 판정되는 가설. 필수 —
  `weakest_link`(이것이 거짓이면 테제가 죽는 사실 주장 한 문장 — 조사가 가장 먼저 깨 본다), primary 1개 이상이 **소·중형**(size_band micro <$0.3B · small <$2B · mid <$10B),
  반증 기한 1개 이상이 **190일 안**, novelty·what_market_misses(ADR-0026). 선택 `parent_key` — 어느 macro(또는 regime)의 어느 고리를 날카롭게 한 것인가.
  DB(`ideas.put_theses`)가 이 형식을 막는다.

### 3. micro 의 출발점 (우선순위)
1. **큰 테제 쪼개기** — 자식이 적은 macro·regime 부터. chain 의 부품 노드에서 그래프 하류(`requires`·`offered_by`)를 두 단계 내려가, 그 변화가 **매출의 가장 큰 비중**으로 닿는 미국·한국 소·중형 상장사의 한 제품 라인.
2. **승격 가능한 약한 신호** — 출처 유형 2+ 또는 3주 안 재등장. 그 신호가 더 쓰게 만드는 것(consumes_more)을 파는 소·중형사.
3. **이슈 경로의 2단계 이상 고리** — 뉴스가 이름을 부른 기업이 아니라, 그 기업의 공급사·장비사. 시장이 읽는 것은 헤드라인 기업이다. (ADR-0026 의 "뉴스는 출발점이 아니다" 는 macro 에 대한 규칙이다 — micro 는 primary 가 뉴스에 이름이 나오지 않을 때만 뉴스에서 출발할 수 있다.)
4. **소형주 공시** (금요일) — 한국 단일판매·공급계약 체결, 미국 8-K item 1.01 중 AI 공급망 소형주.

### 4. 수명
discover 가 stage 0 으로 쓴다 → research 가 weakest_link 를 원문으로 (refuted 면 그날 닫힌다: `put_thesis_research`) → confirmed·partial 이면 report 큐(`v_q_thesis_candidates_needing_report`)로 →
리포트·목표주가(★1 부터, 테제의 반증 조건이 리포트의 weaken 예측) → verify 가 반증 기한·첫 신호(`v_q_thesis_watch`)를 매일 본다: 첫 신호가 나타나면 stage 1, 반증 성립이면 닫는다.
micro 의 성적(닫힌 이유: 반박·반증·확인)은 한 달마다 센다 — 정밀도를 말하려면 틀린 테제도 세어야 한다(재현 교훈).

### 5. 소형 공급사를 우주에 넣는 길 — JSON 그래프 패치
discover 는 그래프에 없는 상장 공급사를 `research/ecosystems/patches/YYYYMMDD_discover.json` 에 노드·간선(간선마다 https 원문)으로 적고 `graph_patches.from_json` 으로 적용, `export_web` 으로 웹 데이터를 맞춘다.
바뀐 파일이 `research/` 와 `apps/web/src/data/` 안뿐이고 CI 가 모두 통과하면 스스로 병합한다 (주간 개선 작업과 같은 문). 가격은 다음 날 수집부터 — 그 전의 조용함 판정은 `unmeasured`, verify 가 다시 잰다.

### 6. 상한
- 새 micro 하루 3개, 활성 micro 40개 (넘으면 그날은 새로 쓰지 않고 verify 가 닫기를 먼저).
- 조사 하루 8개 중 micro 몫 최대 3개. 새 macro 주 1개(토).
- 약한 신호 하루 3~10개 — 요일별 출처: 월 논문 · 화 표준·컨소시엄 · 수 학회·IR 자료 · 목 플랫폼 릴리스·모델 API · 금 채용·소형주 공시 · 토 전 유형 가볍게.

## 결과
- 좋은 점: 테제 발굴이 매일 돈다. 판정이 6개월 안에 나므로 틀린 테제가 빨리 죽고 성적을 셀 수 있다. 소형주가 primary 가 된다. 조사의 반박이 테제를 직접 닫는다.
- 비용: discover 가 길어진다(8~26분 → 40~60분), research 가 기다릴 수 있다. 저장소에 하루 PR 하나가 생길 수 있다. 소형주는 근거가 단편적이라 ★1 리포트가 늘어난다(ADR-0022: ★1 은 결함이 아니다).
- 위험: 작은 테제가 많아지면 질이 떨어진다 → 하루 3개 상한, 반박 우선 조사, 6개월 반증 기한, 월간 성적. 소형주의 유동성·공시 공백은 리포트의 risks 에 쓴다 — 이 시스템은 정보이지 매매 권유가 아니다.
- 바뀐 것: 마이그레이션 `0030_daily_thesis_chain.sql`(scale·parent_key·weakest_link·research, `put_thesis_research`, 큐 뷰 3개, `put_weak_signals` 상태 갱신 수정), 엔진 `hypotheses.from_thesis_queue`,
  `graph_patches/from_json.py`, 문서 `docs/agents/daily/discover.md`(← paths.md)·`research.md`·`report.md`·`verify.md`·`daily-ideas.md`·`thesis.md`(참고서로), 웹 사슬 표시(paths → discover).
