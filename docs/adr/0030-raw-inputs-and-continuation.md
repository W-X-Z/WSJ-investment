# ADR-0030: 원본 입력과 이어받기 — 무엇이 들어오는지 재고, 하루에 끝나지 않는 조사를 잇는다

상태: accepted (2026-11-02). ADR-0028(단서 → 해석 → 투자 아이디어)과 ADR-0029(목적과 방향만)를 그대로 두고, 해석이 **무엇을 읽는가(In)** 와 **조사가 어떻게 이어지는가** 를 바꾼다.

## 맥락 (2026-11-02 측정)
- 사용자는 사흘 동안 "뉴스보다 원본(표준·규칙 초안·학회·특허·채용·코드)에서 국소적 기술 혁신·패러다임 변화를 먼저 잡자"고 했지만, 바뀐 것은 지침 문서뿐이었다. 10/30 이후 병합된 PR 12개 중 수집기를 바꾼 것은 0개였다.
- 11/02 해석의 In: 30시간 동안 777건을 모아 Haiku 가 제목·요약 280자만 보고 582건(75%)을 버렸고, 해석은 195건을 읽었다. 그중 기업 이름 검색 소식 59%, 업계지 27%, 공시 9%, 원본 층(표준·규칙·학회·채용·코드) 0건. 92% 가 이미 그래프에 있는 회사였고, 요약은 평균 79자에 본문은 없었다.
- 해석은 "의미 있는 단서가 없으면 아무것도 쓰지 않는다" 로 60분 중 26분을 쓰고 끝났다. 검토자(06:49)는 초안이 없으면 13초 만에 끝났다. 건너뛴 결정(나이·시총 범위 착오·숫자 후행)은 아무도 다시 보지 않았다.
- 예약 세션은 매번 새로 시작하고, 어제 못 끝낸 조사를 이어받을 곳이 없었다.
- 원문을 못 연 이유는 승인 모드가 아니었다(06:17·06:49 는 이미 '자동'). WebFetch 는 대화에 나온 적 없는 주소(DB 에서 꺼낸 주소)를 열 때 따로 확인을 요청하고, 답할 사람이 없어 거부된다. 같은 글을 WebSearch 로 찾은 주소는 열린다 (10/31 기록).

## 결정
1. **출처에 층을 단다.** raw(표준·규칙·학회·논문·정책·릴리스 노트) · press(업계지) · newsroom · company(기업 이름 검색 소식) · disclosure · issue. 단서의 `extra.layer` 에 남는다.
2. **원본 층의 전문 출처는 분류기가 버리지 않는다.** 출처 자체를 골라 둔 것이기 때문이다. 제목만으로는 관련성이 안 보이는 원본(규정 번호, 표준 문서 번호, 커밋)이 많다. 분야 전체를 내는 원본(arXiv 분야 피드)은 `broad` 로 두어 분류기를 거친다. 한 번 실행에 120건까지.
3. **남긴 단서는 본문을 받아 둔다** (`ideas.clue_texts`, 공개하지 않음). 해석·검토는 본문을 DB 에서 먼저 읽고, 원문 주소가 필요하면 WebSearch 로 찾아 연다. 보존·정리 규칙은 데이터가 쌓인 뒤에 정한다 (사용자).
4. **In 을 잰다.** `ops.v_input_quality`(날마다 층별 건수·원본 비중·그래프 밖 회사 비율·탈락 사유·본문 비율·DB 크기), `ops.v_source_use`(출처별로 남긴 단서와 아이디어가 쓴 수). 05:23 수집이 한 줄, 주간 개선이 표로 본다. 채점이 아니라 상태 확인이다.
5. **조사를 잇는다** (`ideas.threads`·`thread_entries`, `ideas.put_thread`). 해석이 결론까지 못 간 단서와 검토자가 되돌린 약한 고리를 스레드로 연다. 별도 리서처 작업은 만들지 않는다(사용자) — 해석이 남는 시간에 열린 스레드 하나를 이어서 판다. 시간이 모자라는 것이 보이면 그때 떼어낸다.
6. **검토자는 건너뛴 결정도 본다.** 초안이 없어도 해석이 건너뛴 결정 몇 개를 골라 이유가 목적·방향에 맞는지 본다.
7. 채점 항목(예측 장부 A-11, 예측 채점 S-5, 적중률 보정 K-11)은 폐기한다 (사용자). '틀렸다고 볼 신호'는 아이디어 문장에 그대로 둔다.

## 결과
- 원본 수집기(페이지 변화 감지·목록형·API형 출처)는 이 틀 위에 붙는다 — 층이 raw 인 출처를 더하면 분류기를 건너뛰고, 본문이 저장되고, In 점검에 원본 비중으로 보인다.
- 해석이 "쓸 게 없다"로 끝나는 날도 조사는 멈추지 않는다. 쓰지 않는 것은 그대로 허용된다 — 개수가 목표가 아니다.
- 0034 를 적용하기 전에도 수집기는 돈다(본문 저장만 건너뛴다). 스레드·점검 뷰는 0034 뒤부터.
