# ADR-0025: 구조 가설 트랙 — 사용 방식의 변화에서 리레이팅까지

상태: accepted (2026-10-29). ADR-0020(가설 우선)·0022(검증 루프)·0024(작업 분업)의 위에 **수요측 층과 테제 단위**를 더한다.

## 문제
사용자가 원하는 수준: "메모리 반도체 주가 급등 전에, AI 의 발전이 에이전트로 이어져 대용량 컨텍스트·KV 캐시 등 메모리 수요를 예측해 삼성전자·SK하이닉스·삼성전기의 리레이팅을 예측하는 것".
10/29 첫 사슬 실행의 결과물을 읽은 판단: 글은 애널리스트 노트 수준이지만 전부 **어제 뉴스에서 출발한 2홉 공급사 추론**이다. 시장이 이미 본 사실에서 한두 칸 옆으로 간 것이지 먼저 본 것이 아니다. 구조가 반대 방향이다.
1. 출발점이 뉴스 이슈다 — 그 테제는 **기술 사용 방식의 변화**(추론 토큰 폭증, 컨텍스트 길이, 에이전트당 KV 캐시 상주)에서 출발하고, 그런 변화는 이슈 수집기에 안 걸린다.
2. 온톨로지에 수요측 노드가 없다 — gen:hbm4·req:hbm_io 같은 하드웨어 노드뿐, "에이전트 추론 워크로드 → 토큰당 메모리" 로 가는 경로를 그릴 수 없었다.
3. 목표가 텐배거·소형주라 삼성·하이닉스는 '이미 알려진·메가캡' 으로 밀린다. 리레이팅은 대형주의 체제 전환을 맞히는 일이다.
4. 가치평가가 현재 P/S·P/E 에 닻을 내린 12개월 시나리오라 배수 자체가 바뀌는 리레이팅을 표현할 수 없다.
5. 리포트 단위(기업 1 + 이슈 1)에는 여러 달에 걸쳐 근거가 쌓이는 구조 가설을 담을 그릇이 없다.

## 결정
1. **수요 동인 층** `demand_driver`(layer 0)를 온톨로지에 더한다 — 워크로드·사용 방식의 변화(에이전트 추론, 긴 컨텍스트, KV 캐시 상주). `drives_requirement`·`creates_bottleneck` 의 domain 에 들어간다.
   첫 패치 `p20261029_demand_drivers`: 동인 3 → 요구 3(가속기당 메모리·랙당 CPU 메모리·컨텍스트 저장 계층) → 병목 2(HBM·DRAM 비트 공급) → 부품 3(HBM 스택·서버 DRAM/LPDRAM·KV 캐시 SSD) → SK hynix·삼성·Micron. 크기는 관측치(obs:*)로 잰다.
2. **구조 가설(테제)** 을 리포트와 별개의 단위로 둔다 (0028 `ideas.theses` + `thesis_evidence`): 한 문단의 statement, 수요 동인부터 기업까지의 chain, **관측 가능한 drivers**(수치·출처·임계치), beneficiaries(메가캡 허용, 리레이팅 근거 from→to), losers, 날짜 있는 falsifiers, stage(0 가설 · 1 동인이 움직임 · 2 공급 반응이 보임 · 3 시장이 반영), benchmark(유사 과거 사례).
   매일 사슬이 테제의 근거·반증을 쌓는다: 경로 작업은 경로마다 `thesis`(지지·반박하는 테제 key, 없으면 null)를 적고, 검증 작업은 그것을 `thesis_evidence` 로 기록한다. 주 1회 테제 작업이 드라이버를 갱신하고 stage 를 올리거나 닫는다.
3. **벤치마크** `research/benchmarks/regime_cases.json`: 과거에 실제로 일어난 '사용 방식 → 공급망 → 리레이팅' 사례(HBM 2023, ABF 기판 2020, 800G 광모듈 2023, 열·전력 2023, 진행 중인 메모리 추론 2026)마다 사슬·가장 이른 공개 신호와 날짜·시장 반응과 크기·그때 필요했던 데이터를 적는다. point-in-time 재현(그 날짜까지의 공개 정보만으로 테제가 세워지나)의 정답지이고, 새 테제는 가장 닮은 사례를 benchmark 로 단다.
4. **첫 테제** `memory_inference_rerating_2026`(research/theses/): 에이전트 추론 → 토큰당 메모리 → HBM 에서 CPU DRAM·컨텍스트 SSD 로 번지는 2차 파동 → 메모리 3사 리레이팅. stage 1(동인 움직임·공급 부족 확인, 2차 파동의 가격 체제는 확인 중). 수혜 하류에 삼성전기(FC-BGA)를 2차로 둔다.
5. **출처를 바꾼다**: 테제 작업의 1차 출처는 공급망 뉴스가 아니라 수요가 만들어지는 곳 — 모델 릴리스 노트(컨텍스트 길이·가격), 추론 플랫폼 발표(Dynamo·CMX 같은 메모리 계층), 하이퍼스케일러 capex 가이던스, 키노트 수치(토큰 처리량), 업계 데이터(TrendForce 인사이트), 추론 인프라 채용 공고.
6. **리레이팅 가치평가 모드**(다음 PR): 테제의 수혜 기업에는 12개월 P/S 시나리오가 아니라 체제 전환 배수(사이클 P/B·P/E 밴드 → 체제 밴드)로 기댓값을 낸다.

## 개정 1 (2026-10-30) — 리레이팅 가치평가 구현 (결정 6)
`wsj.ecosystems.rerating`: 세후 영업이익 기준으로 (1) 시장 내재 지속 마진 = 시총 / (배수 × 매출 × (1−세율)) (2) 업종 밴드(memory·substrate·equipment — 가정)별 trough·mid·regime 가격 (3) 그 밴드로 지금 시총을 정당화하는 필요 매출 배수. 확률은 정하지 않는다.
첫 측정(2026-10-28 가격, TTM 2026-06): SK hynix 영업이익률 68%, 세후 영업이익 10.9배 — 배수 12배면 **62% 마진이 영원히 간다** 고 가격에 넣고 있다(반토막 뒤에도). 삼성전기 102.7배·테크윙 65.8배·한미반도체 107.2배 — 마진이 아니라 매출 성장(regime 밴드에서도 필요 매출 ×2.5·×1.7·×7.3)을 가격에 넣었다. 가격 기준으로 '조용한'(quiet) 테크윙도 배수로는 조용하지 않다.
