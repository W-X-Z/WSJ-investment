# 2026-10-27 피벗 리뷰 — 공급망 온톨로지·Signal Atlas (PR #1~#8, 98 커밋, +54k 줄)

범위: `fb6d7fb`(브리프 워크플로) 이후 main 까지. 코드 리뷰 2건(파이프라인 / 웹)을 별도 에이전트로 돌리고, 온톨로지는 직접 뜯었다. 이 문서는 **판단과 액션**이 목적이다. 세부 결함 목록은 §4.

## 1. 한 줄 판단

방향(기술 병목 → 공급사 노출을 공개 1차 자료로 추적)은 맞고, 자기 제약(근거 등급 분리·lookahead 금지·"관계 ≠ 매출")을 문서로 잘 세웠다. 그러나 **구현이 문서를 따라가지 못했다**: 그래프는 질문에 답할 수 없는 구조였고(기업 차수 1, 수요 측 노드 0), 5,453건 백필은 절반 이상이 노이즈이며, 6시간 모니터의 LLM 단계는 버그로 매번 실패하면서 비용만 썼다. 웹은 디자인 완성도는 높지만 1.1MB 정적 JSON 을 홈에서 내려받고 레거시 바이오 신호를 "중요 신호"로 띄운다. 개발 난항의 원인은 **데이터 모델을 확정하기 전에 UI·수집·백필을 동시에 벌인 것**이다.

## 3. 남은 핵심 판단 (사용자 결정 필요)

1. **유니버스 재정의.** 현재 유니버스(764사, SIC 버킷)는 피벗 전 것이다. 세 공급망의 상장 공급사 25개 중 유니버스 안에 든 회사는 0개. 제안: 유니버스 = "온톨로지 기업 노드 + 그 기업의 SEC 필러 경쟁사" 로 바꾸고, 기존 바이오·정부조달 수집기는 유지하되 신호·브리프 대상에서 뺀다 (ADR-0013 로 기록).
2. **텐배거 관점과 대형주 공급사의 충돌.** 세 공급망의 핵심 공급사는 대부분 대형주(Vertiv·Coherent·Lumentum·KLA·TI·AMAT). 소형(공개유동 <$2B)은 AEHR·POET·NVTS·VICR·AAOI·CAMT(20-F) 정도. 그래프의 각 병목마다 "독점적 소형 전문 공급사" 가 있는지 묻는 작업이 다음이고, 없으면 그 병목은 투자 아이디어 원천이 아니라 맥락이다.
3. **백필 5,453건의 처리.** 노이즈 비율(hbm 52%·optics 34%·power 84% 무관)이 높아 현재 상태로는 "근거 지표" 가 아니라 오염원이다. 단어 경계 필터를 백필에도 적용해 재생성하거나, `historical-evidence.json`(542KB) 을 웹 번들에서 빼고 서버 조회로 바꾼다. **삭제가 아니라 격리**를 권한다.
4. **모니터 운영 여부.** 6시간 크론이 실제로 돌고 있지만 산출물은 GitHub 이슈 코멘트뿐이고 상태는 30일 아티팩트 체인 하나다. 운영을 계속하려면 상태를 레포(또는 Supabase)에 커밋하고, 멈추려면 크론을 끄고 수동 실행으로 돌린다. 지금처럼 "돌지만 아무도 안 보는" 상태가 가장 나쁘다.
