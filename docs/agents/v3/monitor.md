# 1·2단계 — 영향 경로·후보·선택 (API, `python -m wsj monitor run`)

## 목적
선별(N3)이 진행으로 고른 변화 사건마다 **돈이 움직이는 경로**를 빠르게 짚고, 그 경로에서 이익이 크게 바뀔 미국·한국 상장사를 후보로 올린 뒤, 하루 최대 2건을 깊은 조사로 넘긴다. 깊게 보는 건 3단계 몫이다.

## N4 영향 경로 (`wsj/monitor/paths.py` 의 SYSTEM 이 실제 지시문)
- 사건당 경로 최대 3개. 축: 병목 · 대체 · 시장 파이 확대 · 공급자 협상력 · 기타.
- 사건에 이름이 나온 회사보다 전·후방에서 시총 대비 영향이 큰 작은 회사를 찾는다.
- 산업 그래프 이웃을 먼저 보고, 모자라면 웹 검색(사건당 3번 이하)으로 공급망 위치·고객만 확인한다.
- 헤드라인은 읽기 쉬운 명사형("HBM 고집적화에 따른 유리 인터포저 수요 확대").

## N5 후보 종목
- 티커가 있으면 시세로 확인, 없거나 틀리면 이름으로 찾는다. 미국·한국 밖은 버린다.

## N6·N7 반응과 선택 (`wsj/monitor/pick.py`)
- 사건일 전후 초과 수익률·거래량을 붙인다. 이미 움직였다는 이유만으로 빼지 않는다 — 움직임이 변화의 크기에 비해 충분한지 묻는다.
- 크기(1년 이익·멀티플)·시총 대비 영향·구조의 분명함으로 하루 최대 2건. 서로 다른 사건에서 고른다.
- 고르지 않은 후보도 노션 '아이디어 후보'에 남고, 사용자가 '심층 요청'을 체크하면 다음 실행이 가져간다.

## 비용
진행 사건당 ≈ $0.05~0.1(웹 검색 포함), 선택 ≈ $0.03, 실행당 상한 `--max-usd`(기본 $2). 상한에 닿으면 남은 사건은 `skipped_events` 로 남긴다.
