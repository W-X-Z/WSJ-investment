# 밸류에이션 (N19) · 향후 밸류 (N20)

## 목적
1년 내외 엑시트 기준으로 **지금 가격이 무엇을 가정하고 있는지**, 그리고 **12개월 뒤 시장이 매길 가치가 어디쯤일지**를 정한다.

## 재료
`deep valuation`(현재·과거 배수, 역DCF), `deep peers` 결과, 펀더멘탈·산업 결과, `deep story`(가격 반응).

## 밸류에이션 (현재)
- 지금 배수를 자기 과거·피어와 비교하고, 역DCF 가 요구하는 성장률이 산업 결과에 비춰 높은지 낮은지 본다.
- 최근 큰 등락은 그날 이유와 함께 본다. 이 확인 없이 "과매도", "이미 반영"이라고 쓰지 않는다.

## 향후 밸류 (12개월 시나리오)
- Bear/Base/Bull 마다: 12개월 뒤 시장이 볼 해(FY+1~2)의 매출·이익률, 적용 배수와 그 배수를 정당화하는 근거. 확률은 붙이지 않는다.
- 가정을 JSON 으로 쓰고 `deep scenario --file …` 로 계산한다. 주식 수는 전 종류 희석 주식 수.
- 2배·3배가 되려면 무엇이 맞아야 하는지(`to_reach_at_base_multiple`)를 글로 풀어 쓴다.
- 12개월 안의 계기(실적·수주·정책·허가 일정)를 날짜와 함께.
- 성장 프리미엄을 이익 추정과 배수에 이중으로 넣지 않는다.

## 돌려줄 것
- 밸류에이션 절 초안, 향후 밸류 절 초안(시나리오 표: 가정 · 이익 · 배수 · 주당가치 · 지금 대비 배수)
- scenario 입력 JSON 과 결과 JSON(리포트 data 에 넣는다), 직접 연 출처
