# 펀더멘탈 (N16) + 주가 이슈 정리 (N14)

## 목적
이 회사가 **실제로 돈을 어떻게 벌고 있고, 숫자가 왜 그렇게 움직였는지** 설명한다. 아이디어가 맞으려면 숫자의 어느 줄이 바뀌어야 하는지 짚는다.

## 재료
`deep fin`(연도별·TTM 표, 크게 튄 값), `deep profile`(구조 카드·연도별 변화), `deep story`(크게 움직인 날·같은 날 공시), 최근 10-Q·8-K EX-99(실적 보도자료).

## 방향
- 크게 튄 값마다 원인을 카드·8-K·실적 콜에서 찾아 붙인다(가격·물량·제품 비중·일회성·회계·인수).
- 회사 고유 지표(백로그·RPO·선수금·가동률·ASP 등)를 표에 더한다. 숫자는 원문을 직접 열어 확인한다.
- 재무 구조의 약한 곳(차입 만기·희석·TRA·운전자본)을 짚는다.
- 주가 이슈: `story` 의 날짜마다 그날 주가를 움직인 공시·뉴스·의견을 찾아 한 줄씩. 번호는 story 의 n 을 그대로 쓴다(차트 표시와 같게).

## 돌려줄 것
- 펀더멘탈 절 초안(두괄식 한두 문장 + 연도별 표 + 원인 글머리표)
- 주가 이슈 절 초안(번호·날짜·이슈 한 줄)
- 직접 연 출처 목록(url·제목·날짜)
