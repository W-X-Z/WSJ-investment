# 상상 단계 (③) — 원천에서 초기 투자 아이디어를 만든다

구독 예약 작업의 최상위 모델이 맡는다. 서비스의 가치는 여기서 나온다.

## 목적
매일 들어온 원천(정책·논문·업계지·공시·릴리스 노트)을 읽고 "이거 산업 구조가 바뀌겠는데" 싶은 데이터를 짚는다. 그 변화가 1년 안에 어떤 회사의 이익이나 배수를 바꿔 **주가 2~3배**까지 갈 수 있는지 상상해 초기 아이디어로 남긴다. 검증은 다음 단계가 한다. 여기서는 그럴듯함보다 **크기와 새로움**을 우선한다.

## 입력
- `python -m wsj ideate digest --days 3 --out digest.md` — 출처 종류별·번호(c<clue_id>) 붙은 원천 목록
- 최근 초기 아이디어(`seeds:` 보고서)와 리서치 리포트 제목 — 같은 것을 반복하지 않고, 이어지는 것은 이어서 쓴다
- 필요하면 몇 번만: `python -m wsj deep search '"구절"'`(SEC 공시 전문검색), 웹 검색

## 무엇을 찾나 (유형)
- **새 병목** (`bottleneck`): 수요가 늘 때 늘리기 어려운 고리. 예) AI 학습 → HBM, CoWoS → 본딩 장비, 광 트랜시버 → InP 기판, 전력망 → 변압기
- **점유율 재편** (`share_shift`): 기술·규제·특허·인증이 누가 파는지를 바꾼다
- **시장 파이 확대** (`pie`): 수요 자체가 커진다. 예) AI 전력 → 원전·가스터빈, 랙 발열 → 액체 냉각
- **대체** (`substitution`): 새 방식이 기존 것을 밀어낸다. 예) 랙 안 구리 → 광·AEC, AC 배전 → 800V DC
- **2차 효과** (`second_order`): 한 단계 건너 생기는 부족·가격 변화. 예) HBM 쏠림 → 범용 DRAM 부족, 에이전트 KV 캐시 → SSD
- **정책·공급 통제** (`policy`): 규제·수출통제·보조금이 공급이나 수요를 묶는다. 예) 희토류 통제, HALEU

사례는 모양을 잡는 참고일 뿐이다. 데이터에서 출발한다.

## 하나의 초기 아이디어에 쓸 것 (`seeds.json`)
`id, archetype, headline(명사형 한 줄), hypothesis(무엇이 바뀌고 누가 버는가), chain(→ 로 이은 인과 사슬), why_now(지금 데이터의 근거), must_be_true(맞아야 할 것 2~4개), evidence(clue_id), companies(name·ticker·market us|kr·role·why)`

- 미국·한국 상장사만. 대형주는 2~3배가 어렵다 — 가치사슬의 소재·부품·공정·장비 층 중소형을 먼저 본다.
- 하루 4~8개. 같은 날 같은 주제는 하나로.
- 이미 모두가 아는 이야기라도 버리지 않는다. 대신 "시장이 아직 안 믿는 부분"이 어디인지를 적는다.

## 다음
`python -m wsj ideate check --file seeds.json` → 시총·최근 등락·52주 고점 대비·역DCF가 붙는다. 이걸 보고 1~2건을 `status: "selected"` 로 바꾸고 `ideate save`. 선택 기준은 크기(2~3배 여지) × 가치 포착(이 회사가 돈을 가져가나) × 가격에 덜 들어감 × 12개월 안의 계기. 선택된 건은 3단계 심층 리서치(orchestrator.md)로 간다.

고르기 전에 한 번 더 본다(2026-11-09 Rogers 파일럿에서 배운 것): 회사가 이미 같은 이야기를 Investor Day·가이던스로 내놓았는지, 1년 주가가 그 이야기로 이미 크게 올랐는지(`changes.1y`, 52주 고점 대비). 그렇다면 '시장이 아직 안 믿는 부분'이 무엇인지 한 줄로 쓰지 못하면 고르지 않는다. 보도 속 공급사 명단에 후보 회사가 실제로 나오는지도 먼저 확인한다.
