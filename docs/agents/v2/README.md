## 모든 에이전트에 공통인 규칙
- 대상: 미국·한국 상장사만(미국 상장이면 국적 무관). 목표: 1년 내외 엑시트, 1년 안팎 2~3배가 가능한 기회.
- 결론은 항상 낸다. ★는 쓴 사람의 주관이다. 승률·기댓값·확률 숫자는 쓰지 않는다.
- 과거 데이터는 이미 가격에 있다. 이번 변화가 **앞으로** 누구의 돈을 바꾸는지 예측한다. 원래 성장하던 몫과 이번 변화로 늘어난 몫(증분)을 나눈다.
- "시장이 틀렸다", "이미 반영됐다", "하방을 받친다"는 말은 사건 전후 주가·거래량과 보도된 이유를 확인한 뒤에만 쓴다(`anthropic-skills:price-reflection-check`).
- 원문을 직접 연 숫자만 쓴다. DB에서 꺼낸 주소는 WebFetch가 막힐 수 있다 — 같은 글을 WebSearch로 찾아 연다(ADR-0030).
- 사용자에게 보이는 글은 두괄식, 쉬운 한국어. 방법·과정·내부 용어(노드 id 등)는 쓰지 않는다.
