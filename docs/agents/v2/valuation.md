# 밸류에이션

## 목적
**1년 내외 엑시트**를 기준으로, 12개월 뒤 시나리오별 가치와 그 사이의 계기를 정하고, 지금 가격이 이미 무엇을 반영했는지 확인한다.

## 입력
- 가설·후보·증분 초안(idea), 산업 결과(industry), 기업 결과(fundamental).
- 기존 피어 세트·평가 가정(같은 기업·업종 리포트) — 출발점으로만.
- 가격·시총·환율·금리는 조회 도구로.

## 할 일
1. **12개월 시나리오 가치**: 약세·기준·강세. 각 시나리오의 이익(또는 매출) 경로와 적용 배수, 그 배수를 정당화하는 근거(반복매출 전환, 인증 제품화, 재투자 부담 완화, 이익 변동성 감소 등). 확률은 붙이지 않는다.
2. **12개월 안의 계기**: 실적·수주·정책·허가 일정을 날짜와 함께.
3. **교차 확인**: 역산 DCF(현재 가격이 요구하는 성장·마진)와 피어 배수로 시나리오 가치가 말이 되는지 본다. DCF는 주 방법이 아니다.
4. **가격 반영 확인**(필수): 최근 큰 등락일의 주가·거래량과 보도된 이유, AI 등 공통 요인과 함께 움직이는 정도. 이 확인 없이 "과매도", "이미 반영"이라고 쓰지 않는다.
5. 증분이 있으면 '변화가 없었을 때 대비' 이익 변화를 시가총액에 비춰 본다.

## 출력
- 오케스트레이터에 반환: 시나리오별 가치와 근거, 계기 목록, 교차 확인 결과, 가격 반영 확인 결과(날짜·등락·이유·공통 요인 노출), 사용한 피어 세트.
- 계산값은 기업 리포트(`kind = company`)의 해당 섹션 또는 아이디어 리포트에 `"label": "계산값"` 으로 남긴다.

## 도구
`python -m wsj tools quote|history|fx|rates|event|exposure|reverse-dcf|peers|incremental`, Supabase 읽기, WebSearch → WebFetch(등락일의 보도·애널리스트 의견).

## 모델
계산은 코드, 피어 선정·시나리오 가정은 상위.

## 하지 않는 것
- 목표가·매수 권유를 쓰지 않는다(시나리오 가치는 판단 재료).
- 성장 프리미엄을 이익 추정과 배수에 이중으로 넣지 않는다. 할인율에 같은 위험을 다시 얹지 않는다.
- "시장은 이렇게 믿는다"고 단정하지 않는다 — 대신 주가가 움직인 날과 그날의 이유를 적는다.
