# 부족기 이중 발주
- 언제: 공급 부족이 1년 넘게 이어지고, 상류(소재·부품·장비)에서 '수주 사상 최대' 가 연달아 나올 때.
- 메커니즘: 부족기에는 고객이 여러 공급사에 겹쳐 주문하고 재고를 쌓는다. 상류로 갈수록 주문이 실제 수요보다 부풀고, 부족이 풀리는 순간 한꺼번에 취소된다 (채찍 효과).
- 단서로 보이는 모습: 리드타임이 계속 늘어나는데 최종 수요(출하) 증가는 그보다 느림, 같은 부품을 여러 공급사가 동시에 대량 수주.
- 반대 신호(=진짜 수요): 최종 제품 출하가 같은 속도로 늘어남, 장기 공급 계약에 선급금, 고객 재고가 낮음.
- 사례: 2021~22 ABF 기판·반도체 장비 사이클(역사적 사례). 현재 사례 없음.
- 관련 노드: bottleneck:substrate_capacity, bottleneck:abf_single_source, bottleneck:dram_bit_supply
