# 사용자 지적 (해석·패턴에 반영할 것)

대화에서 사용자가 해석·아이디어에 대해 지적한 것을 한 줄씩 적는다. 주간 반성이 패턴 카드에 반영하고 줄 끝에 `→ 반영: <카드>` 를 붙인다.

- 2026-10-30: 공시는 이미 알려진 사실 — 공시보다 작은 이슈(출시·협약·샘플·초도 수주·채용·전시회)를 먼저 본다. → 반영: lenses.md 수집 원칙, interpret.md §2
- 2026-10-30: 빈도·점수 누적 같은 정량 규칙보다 해석이 중요하다. → 반영: README.md, ADR-0028
- 2026-10-30: 제목은 '[원인]에 따른 [대상] [변화]' 명사형 (예: HBM 고집적화에 따른 유리 인터포저 수요 확대). → 반영: docs/agents/writing.md
- 2026-10-30: 공시는 후행성 데이터 — 뒤로 미룬다 (DART 키 등록·공시 API 확대 보류. 해석은 공시를 맨 나중에, 기존 아이디어 갱신용으로만). → 반영: interpret.md §2, BACKLOG A-7
