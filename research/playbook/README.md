# 참고 자료 (playbook) — 규칙이 아니라 기억 (ADR-0028, 2026-10-31 개정)

해석·보강 작업이 필요할 때 꺼내 보는 자료다. 화면에는 나오지 않는다.
시장은 매번 다르다 — 여기 있는 것을 따를지, 무시할지, 반대로 쓸지는 그 사례를 보고 판단한다 (사용자, 2026-10-31).

- `lenses.md` — 단서를 볼 때 떠올려 볼 만한 질문들 (매출 분해 · 병목과 이익 이동 · 대체 · 파이 · 단서의 다른 설명 · 부족기 증폭 · 시장 기대 · 누가 지키나).
- `patterns/*.md` — 여러 해석에서 반복된 메커니즘에 이름을 붙인 카드. "이런 모양을 전에 봤다"는 기억이다. 맨 위에 `상태: 가설` 이 있으면 사례 결과가 나오기 전의 카드다.
- `feedback.md` — 사용자가 중요하게 여긴다고 말한 것의 기록. 방향은 `docs/agents/daily-ideas.md` 에 정리돼 있다.

## 패턴 카드 형식
```
# <이름>
- 언제: 어떤 부품·시장·국면에서 나타나나
- 메커니즘: 왜 그렇게 되나
- 단서로 보이는 모습: 어떤 작은 단서가 이 패턴의 시작인가
- 반대 신호: 이 패턴이 아니라는 증거
- 사례: 아이디어 key·날짜·결과
- 관련 노드: 그래프 노드 id
```
해석 작업은 새 사례를 기존 카드에 더하거나 새 카드를 PR 에 넣을 수 있고(`research/` 안이라 스스로 병합), 주간 작업은 카드를 합치거나 고칠 수 있다.
