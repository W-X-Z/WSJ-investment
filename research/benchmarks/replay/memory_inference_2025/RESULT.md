## 부가 측정
- **(i) 시차**: 사슬의 가장 이른 근거는 2025-03-18(Dynamo 발표, KV 를 CPU RAM·SSD 로), 가장 늦은 것 2025-09-24(TrendForce 4Q25 계약가). 기준일 → 가격 고점 약 9개월(SK hynix 2026-06-22). 기준일 이전 가격이 DB 에 없어 "기준일에 이미 얼마나 올라 있었나" 는 측정하지 못했다 — "시장보다 먼저" 의 분모가 비어 있다.
- **(ii) 반증 조건의 사후 성립**: 심판의 반증 5개 중 마지막("레퍼런스 스택이 KV 압축을 기본으로 하고 호스트 계층을 뺌", due 2026-06-30)은 방향이 맞는 신호가 이후 나타났다 — 2026-10 DeepSeek-V4.1-Flash 전역 KV 890B/토큰, "KV 용량이 배치 크기를 제한하는 일이 드묾"(`research/coefficients`). 리레이팅 고점(2026-06) 뒤 반토막과 시점이 겹친다. 나머지 넷(3Q25 실적·capex 가이던스·Micron FQ1-26·TrendForce 1Q26)은 이번에 확인하지 않았다.
- **(iii) 놓친 고리**: 삼성전기(FC-BGA) — 203,500 → 2,270,000원(2026-06-19, **+1,015%**). 세 갈래 스캔 어디에도 서버 기판 행이 없었다. 한미반도체·테크윙 같은 2차 파동 장비주도 심판 테제에 없다. 스캔이 "수요가 생기는 곳" 에 집중하면 **하류 병목(기판·패키징)** 을 놓친다 — 테제 작업 2부에서 chain 을 기업까지 내릴 때 그래프 하류를 반드시 훑게 한다.

## 사전 등록과 다른 점
1. arXiv API 와 검색 페이지가 WebFetch 에서 거부됐다. 우회하지 않고 WebSearch(arxiv.org 한정) + 허용된 초록 페이지로 찾았다 — **검색 순위는 지금 계산되므로** 이후 많이 인용된 논문이 더 잘 보였을 수 있다(사후 편향 경로 하나 추가). 7행은 날짜순 cs.AR 목록에서 왔다.
2. 채용 공고는 날짜가 보이는 것이 없어 0행. 삼성 2Q25 원문은 거부되어 빠졌다(삼성은 TrendForce 순위로만). Anthropic 2025-08 1M 컨텍스트 발표도 거부로 빠졌다.
3. 스캔 지시문의 주제 목록에 "KV cache·HBM capacity" 가 다른 생태계 주제와 함께 들어 있었다 — 원래 스캔과 같은 목록이지만, 메모리 계층을 명시한 것 자체가 유도였을 수 있다.

## 읽는 법 — 이 결과가 말하는 것과 말하지 않는 것
- **말하는 것**: 2025-09-30 에 공개돼 있던 1차 자료(플랫폼 코드·API 가격·사용량·공시·가격 보고)만으로, ADR-0026 절차가 메모리 3사 리레이팅의 **메커니즘과 수혜 기업**을 1순위로 세울 수 있었다. 그 근거는 뉴스가 아니라 플랫폼 릴리스와 API 가격표에서 나왔다 — 구조 재설계의 방향이 맞다는 첫 증거다.
- **말하지 않는 것**: (1) 모델(스캔·심판 모두)이 2026-06 까지 학습돼 결과를 안다 — 원문·날짜 요구와 결과 비공개로 줄였을 뿐 없애지 못했다. 이 적중은 **상한**이다. (2) 사례 하나다. 정밀도는 5개 중 2 적중·2 놓침·1 미측정 — 우주가 크게 오른 기간이라 "놓침" 도 절대 손실은 작았다. (3) 크기(7배)와 시점(9개월)은 맞히지 못했다 — 테제는 방향과 수혜자를 냈고, 가치평가(T-2)·계수표(T-4)는 이번 재현에 없었다.
- **다음**: 같은 절차를 결과가 반대였던 시점(예: 2022-06 메모리 하강 직전)에 돌려 오탐을 세고, hbm_2022(2022-11)로 두 번째 적중 사례를 시험한다.
