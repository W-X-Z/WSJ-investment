# 주간 매크로 배경 (백로그 J-3)

주간 개선 작업(일요일 10:23)이 매주 한 장 `YYYY-Www.md`(예: `2026-W45.md`)를 쓰고, 해석 작업(06:17)이 가장 최근 것을 읽는다.
목적은 하나다 — 소·중형 기회를 판단할 때 **지금 시장이 무엇을 이미 가격에 넣고 있고, 소형주에 돈이 들어오는 환경인지**를 해석이 알고 판단하게 하는 것.
예측·전망·권유는 쓰지 않는다. 직접 연 원문의 숫자만, 날짜와 링크를 붙여서.

## 한 장에 담는 것 (쓸 만한 것만, 1쪽 안)
- 소형주 환경: 러셀2000·S&P600 대 S&P500 (주간·3개월), 소형주 신규 상장·유상증자 분위기, 신용 스프레드(하이일드).
- 금리·달러: 미국 10년·2년, 연준 일정, 달러(DXY)·원/달러·대만달러 — 해외 공급사 실적 환산에 닿는 것.
- 반도체 사이클: SOX 대 S&P500, 메모리 현물·계약 가격(DRAMeXchange·TrendForce 발표), 한국 반도체 수출(1~20일·월), 대만 주요사 월매출, TSMC 월매출.
- AI 수요: 하이퍼스케일러 설비투자 가이던스 변화(그 주 실적이 있었을 때), 대형 모델·데이터센터 발표.
- 전력: PJM 용량 가격·ERCOT 대형 부하 대기열, 천연가스 가격, 변압기·개폐장치 리드타임 보도.
- 이번 주에 바뀐 것 세 줄: 지난주 대비 무엇이 달라졌나.

## 형식
```
# 2026-W45 (11/02~11/08) 매크로 배경
작성: 2026-11-08 (주간 개선)
## 소형주 환경
- 러셀2000 주간 +1.2%, S&P500 +0.4% — [출처](https://…) (11/07 종가)
…
## 이번 주에 바뀐 것
- …
```
해석은 이 장을 판단의 배경으로만 쓴다 — 개별 아이디어의 근거는 그 회사의 원문이다.
